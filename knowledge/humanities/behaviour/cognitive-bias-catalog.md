# Cognitive Bias Catalog

Index compiled from https://cognitivebiasindex.com/ (2026-08-13). This is a working subset for product, research, and agent-system design. Do not treat the site as a textbook substitute.

## Compiled Truth
- Automation bias: over-trust automated outputs; correct human judgment gets overridden. Counter: keep monitoring, know failure modes, question high-stakes machine output.
- Authority bias: titles and confident tone substitute for argument quality. Counter: demand relevant expertise and the actual reasoning.
- Confirmation / congruence / backfire: search and stop at supporting evidence; identity threat hardens beliefs. Counter: pre-commit "what would change my mind", steel-man, red-team.
- Availability / anecdotal / base-rate neglect: vivid cases beat statistics. Counter: start from base rates.
- Anchoring / framing / decoy: first number and option set construct preference. Counter: independent estimate before seeing comparables.
- Planning fallacy / overconfidence / Dunning-Kruger: underestimate own task time; novices cannot see their incompetence. Counter: reference-class forecasting, outside view.
- Sunk cost / status quo / endowment: past spend and ownership lock decisions. Counter: evaluate remaining value, not paid cost.
- Bias blind spot: you see others' biases more easily than your own. Structured checklists beat introspection.
